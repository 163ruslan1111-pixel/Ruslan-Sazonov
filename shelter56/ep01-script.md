# УБЕЖИЩЕ 56 · Серия 1 · «Убежище 56»

**Логлайн:** двести лет жители убежища ждут приказа из Москвы — а девятнадцатилетний техник узнаёт, что приказа не будет, а реактор умрёт через три месяца.
**Хронометраж:** ~10:00 · 16:9 · речь русская, субтитры английские.
**Карта:** ~75 генераций Kling по 5–10 с (К1…К75). Номер куска = порядок монтажа.
**Крючок в конце:** Алёша видит небо · Начальник докладывает кому-то по рации · из руин за Алёшей следит Фонящий.

Музыка — только на монтаже. В генерациях — звук сцены (если модель его не даёт — звук кладу я).

## Канон диалога (на утверждение)

Реплики, на которых держится серия — не выкидывать:
- «Ваше место уже закреплено» (реклама) — ирония всего фильма.
- «Открывай Пятьдесят шестое» / «Мест нет, Витя. Закрывай» / «Тогда без меня» — завязка Семёныча.
- «Сегодня — день ожидания номер семьдесят три тысячи шестьсот» — абсурд убежища.
- «Реактор в норме. Это приказ» — и свет гаснет на его повторе.
- «Говорит Москва. Ждите приказа» + покашливание — Алёша узнаёт петлю.
