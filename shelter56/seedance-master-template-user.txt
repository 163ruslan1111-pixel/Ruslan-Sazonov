ИНСТРУКЦИЯ ПО ЗАПОЛНЕНИЮ
Замените значения в [квадратных скобках] данными проекта. Скопируйте английский шаблон ниже в промпт. Повторите блоки Image Reference для каждого персонажа и Timeline для каждого кадра. Удалите инструкции и незаполненные варианты перед использованием.

ОБЯЗАТЕЛЬНЫЕ ПРАВИЛА ПРОЕКТА
1. Каждый проект всегда создаётся с указанием режиссёрского стиля. Director / Style Reference — обязательный раздел: имя режиссёра само по себе недостаточно. Опишите его влияние на постановку, операторскую работу, композицию, монтажный ритм, движение камеры, атмосферу, юмор/напряжение и экшен.
2. Основной промпт пишется на английском. Все русские реплики внутри английского промпта записываются ТОЛЬКО латинской транскрипцией: без кириллицы и без перевода на английский. Например: «Ты серьёзно?» → "Ty seryozno?". Язык звучащей речи остаётся русским.
3. Сетка на референсе — только техническая разметка. Она не является частью лица, кожи, волос или одежды и не должна появляться в результате. Наличие сетки не является основанием для генерации нового лица или изменения личности персонажа. Сохраняйте лицо под сеткой максимально точно.
4. Для продолжения ролика первый кадр должен бесшовно продолжать последний кадр непосредственно предыдущего видео. Не начинайте сцену заново.
5. Для новой сцены сохраните разделы Video Reference / Continuity и Continuity Lock, указав, что предыдущего видео нет. Не оставляйте ссылку @Video1 без прикреплённого видео.
6. Временные интервалы Timeline должны покрывать всю заявленную длительность без пробелов и наложений. Реплики и действия должны помещаться в отведённое время.
